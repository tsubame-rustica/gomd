# ブランチの命名規則あれこれ

基本的なブランチの種類です[1]．

| ブランチ名 | 役割 | 派生元 |
| --- | --- | --- |
| main | 公開するものを置くブランチ | - |
| develop | 開発中のものを置くブランチ | main |
| feature/〇〇 | 新機能開発中に使うブランチ | develop |
| fix/〇〇 | バグ修正用ブランチ | develop |

例えば，ログイン機能を実装する場合は，`feature/addLogin` と命名できます（他にも命名の仕方はあります）

また例で示した`addLogin` は`add` と`login` という単語で構成されています．

このように複数の単語からなるブランチ名は単語同士の繋げ方がいくつかあります．

| 名称 | 説明 | 例 |
| --- | --- | --- |
| ローワーキャメルケース | 最初の単語を小文字にし，それ以降の単語の先頭を大文字にする形式 | `addLogin` |
| アッパーキャメルケース | 全ての単語の先頭を大文字にする形式 | `AddLogin` |
| ローワースネークケース | アンダースコア（`_` ）で単語を区切る形式 | `add_login`  |
| アッパースネークケース | 全て大文字で記載し，アンダースコアで単語を区切る形式 | `ADD_LOGIN` |
| ケバブケース | ハイフン（`-`）で単語を区切る形式 | `add-login` |

この5つのケースが主に使われています．このうち，ブランチ名はローワーキャメルケースやローワースネークケース，ケバブケースを使用するのが良いと思います．
